Image files to Zarr in the browser

Paste the URL of an image file, a Zarr or N5 store, or a .vzip archive. TIFF and OME-TIFF, Aperio SVS, Hamamatsu NDPI, Nikon ND2, Zeiss CZI, DICOM, NIfTI and Imaris IMS files, N5, Zarr v2 and OME-Zarr 0.4 stores, and Sentinel-2 SAFE products are supported; the format is detected from the file's first bytes, or the store's metadata. A service worker reads the input's structure with a few range requests, writes a vzip archive in memory (by spec/virtualize.md), and serves it as plain Zarr at a local URL that any Zarr viewer on this site can open: Neuroglancer, or for Sentinel-2 a map. Pixel data is read from the original only when a viewer asks for it.
