Image files to Zarr in the browser

Paste the URL of an image file or a .vzip archive. Tiled TIFF and OME-TIFF, Aperio SVS, Hamamatsu NDPI and Nikon ND2 files are supported; the format is detected from the file's first bytes. A service worker reads the file's structure with a few range requests, writes a vzip archive in memory (by VIRTUALIZE.md), and serves it as plain Zarr at a local URL that any Zarr viewer on this site can open. Pixel data is read from the original file only when a viewer asks for it.

Examples: IDR idr0096, mouse bone marrow (OME-TIFF, 487 MB, JPEG 2000) · S-BIAD3015, E. coli time-lapse (Nikon ND2, 4.6 GB) · S-BIAD2077, 5-channel z-stack (Nikon ND2, 263 MB) · TCGA colon H&E (Aperio SVS, JPEG 2000, 538 MB) · QuPath Ki67 lymphoma (Hamamatsu NDPI, 221 MB)
