vzip in the browser

Paste the URL of a tiled TIFF or OME-TIFF (or of a .vzip archive). A service worker reads the TIFF's directories with a few range requests, writes a vzip archive in memory, and serves it as plain Zarr at a local URL that any Zarr viewer on this site can open. Pixel data is read from the original file only when a viewer asks for it.

Example: IDR idr0096, mouse bone marrow (OME-TIFF, 487 MB, JPEG 2000)
Zarr URL:
levelshapechunkdata typecodecs
